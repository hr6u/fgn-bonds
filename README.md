## 📦 Overview

fgn-bonds is a modern web application designed for FGN Savings Bond subscriptions. It features a user-friendly 7-step form wizard, PDF generation, payment tracking, and DMO reporting. This app simplifies the bond subscription process, making it easy for anyone to invest in government bonds.

## ⚙️ Features

- **7-Step Form Wizard**: Navigate through the subscription process with ease.
- **PDF Generation**: Download your transaction receipts in a simple and clean format.
- **Payment Tracking**: Keep track of your investments and transactions.
- **DMO Reporting**: Access detailed reports from the Debt Management Office.
- **Responsive Design**: Enjoy a seamless experience on both desktop and mobile devices.
- **Built with React and FastAPI**: Fast and modern technologies for a smooth user experience.
